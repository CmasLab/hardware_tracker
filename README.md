# Hardware Tracker

Sistema de gestion y trazabilidad de hardware orientado a laboratorios, prototipado e investigacion aplicada del Centro C+.

## Resumen

Hardware Tracker busca centralizar el registro de equipos, prototipos y dispositivos tecnologicos, permitiendo controlar su inventario, versionado, historial de modificaciones, prestamos y responsables asociados.

La plataforma esta pensada para reducir perdidas de equipamiento, mejorar la organizacion interna del laboratorio y facilitar la continuidad tecnica de proyectos de investigacion y desarrollo, especialmente en entornos maker y de prototipado rapido donde los dispositivos evolucionan constantemente.

## Objetivo

El objetivo principal del proyecto es entregar una herramienta que permita identificar, registrar y seguir el ciclo de vida de cada equipo o prototipo mediante un ID unico, manteniendo trazabilidad completa sobre su estado, ubicacion, uso, responsables y cambios tecnicos.

Ademas de funcionar como inventario, el sistema busca transformarse en una herramienta de gobernanza tecnica y memoria institucional para el ecosistema de desarrollo tecnologico del centro.

## Trazabilidad del hardware

Cada equipo registrado podra mantener informacion historica y operativa sobre:

- ID unico del equipo o prototipo.
- Ubicacion actual.
- Estado operativo.
- Responsable asignado.
- Historial de uso.
- Prestamos y devoluciones.
- Cambios de hardware.
- Cambios de firmware.
- Evolucion de versiones fisicas y funcionales.

## Alcance funcional

El sistema considera funcionalidades orientadas a:

- Registro centralizado de equipos, dispositivos y prototipos.
- Control de inventario de hardware.
- Seguimiento de responsables y usuarios asociados.
- Registro de movimientos, prestamos y devoluciones.
- Historial de modificaciones tecnicas.
- Versionado de prototipos y dispositivos en desarrollo.
- Consulta de estado y ubicacion de cada elemento registrado.

## Integraciones futuras

El proyecto podra integrarse en el futuro con:

- Codigos QR para identificacion rapida de equipos.
- Documentacion tecnica asociada a cada dispositivo.
- Repositorios GitHub vinculados a firmware, software o documentacion.
- Registros fotograficos de prototipos y componentes.
- Seguimiento de mantenimiento, reparacion o intervenciones tecnicas.

## Contexto de uso

Hardware Tracker esta orientado a laboratorios, espacios maker, equipos de investigacion aplicada y unidades de prototipado que trabajan con dispositivos en constante evolucion. En estos entornos, mantener una memoria tecnica clara permite mejorar la continuidad de los proyectos, evitar duplicacion de esfuerzos y disminuir el riesgo de perdida de informacion o equipamiento.
